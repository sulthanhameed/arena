# Frontend Source Manifest

The actual frontend source code lives at the **repository root** in `/src/`
because Vite + `vite-plugin-singlefile` need `index.html` and `package.json`
co-located at the build root.

## Live source location:

```
/src/
  App.tsx
  main.tsx
  index.css
  components/   (25 files)
  context/      (2 files — Auth (Supabase session), Cart)
  lib/          (4 files — supabase.ts, api.ts, payments.ts, razorpay.ts)
  types/        (1 file — database.types.ts, generated from the SQL schema)
  hooks/        (1 file — useScrollReveal.ts)
  data/         (1 file — menu.ts, offline fallback)
  utils/        (1 file — cn.ts)
```

To browse the code:
```bash
cd ../../src
ls -la
```

To run the dev server:
```bash
cd ../..        # back to repo root
npm run dev
```
